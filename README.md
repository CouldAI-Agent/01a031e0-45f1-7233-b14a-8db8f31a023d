# HeartSpace

HeartSpace is a beautifully designed, cross-platform Flutter application for expressing and sharing your feelings. The app acts as an emotional journal where users can select their current mood via interactive emoji chips and expand on their thoughts with a simple, distraction-free interface. 

## Features
- **Emotion Feed:** View a chronological feed of shared feelings, showing the specific mood, an icon, the relative time, and the text.
- **Mood Selector:** An interactive chip array mapping common emotions (Happy, Sad, Angry, Anxious, Calm, Excited, Grateful, Tired) to emojis.
- **Responsive Layout:** Adaptive maximum width constraints ensuring the app looks gorgeous on Mobile, Desktop, and Web.
- **Modern UI/UX:** Built with Material 3 styling, pastel container backgrounds, and gentle rounded corners.

## Getting Started

Make sure you have [Flutter](https://flutter.dev) installed on your machine.

1. Install dependencies:
   ```bash
   flutter pub get
   ```
2. Run the application:
   ```bash
   flutter run
   ```
